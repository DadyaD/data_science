# Прогнозирование остаточного ресурса и детектор деградации (NASA CMAPSS)

Два компонента предиктивного обслуживания по телеметрии авиадвигателя:
регрессия остаточного ресурса (RUL) и детектор начала деградации.
Оба валидированы на данных, которых не видели при разработке.

## Задача

Остановка оборудования дороже обслуживания по состоянию. Регрессия отвечает
«сколько циклов осталось», детектор — «началась ли деградация». Компоненты
комплементарны: детектор включает внимание, регрессия планирует замену.

## Данные

[NASA CMAPSS](https://www.nasa.gov/intelligent-systems-division/discovery-and-systems-health/pcoe/pcoe-data-set-repository/), FD001:
100 обучающих + 100 тестовых двигателей, 21 сенсор + 3 параметра режима,
один тип отказа (деградация компрессора высокого давления). В train запись
обрывается в момент отказа; в test — до отказа (цензурирование).

Датчики идентифицированы физически: sensor_9 (~9000 об/мин) — частота
вращения ротора и т.д. Каналы со std &lt; 0.01 отброшены (в FD001 это
константы симуляции). Ограничение метода: фильтр по std пропускает
шумные, но несигнальные каналы (на FD003 — sensor_6, квантованный датчик
с 17 уровнями).

## Методология

1. EDA, физическая идентификация каналов, отбор признаков.
2. Таргет RUL = (макс. цикл − текущий), клип сверху 125 (кусочно-линейная
   модель деградации NASA).
3. Валидация: GroupKFold по двигателям (строки одного агрегата
   коррелированы — случайное разбиение дало бы утечку), GridSearchCV,
   единственный прогон на test в самом конце.
4. Детектор: персональный эталон (первые 30 циклов), коридор 2σ, тревога
   при уходе скользящего среднего (окно 5) с удержанием 5 циклов.
   На каждой итерации оценивались два критерия: запас предупреждения И
   ложные тревоги в здоровой зоне (RUL &gt; 125, цикл &gt; 30) — одна маска
   для всех версий.
5. Оценка детектора на тесте с учётом цензурирования: подгруппы по
   глубине наблюдения + кривая Каплана–Майера.

## Результаты: модель RUL

| Модель | Протокол | RMSE |
|---|---|---|
| Линейная регрессия | test | ~21 |
| LightGBM (500 деревьев) | test | 17.81 |
| LightGBM + rolling-признаки | test / CV | 18.29 / 18.70 |
| **LightGBM (тюнинг, финал)** | **CV / test** | **18.70 ± 0.59 / 17.92** |

Негативный результат: rolling-признаки не улучшили бустинг (проверено в
двух протоколах) — задокументирован, в финальной модели не используются.

## Результаты: детектор деградации

| Подход | Ложные тревоги (здоровая зона) | Медианный запас |
|---|---|---|
| A: парковый эталон, z-score | 0.1% строк, 5% двиг. | 16.5 цикла |
| B: эталон по здоровой зоне | 36.7% строк, 99% двиг. | 194 |
| C: персональный, точечный | 66.8% строк, 100% двиг. | 167 |
| **T: устойчивый дрейф (финал)** | **3.6% строк, 21% двиг.** | **94.5** |

Train — 100% обнаружения. **Test (unseen): медианный запас 91.5 цикла,
обнаружение 98% (двигатели, чьё наблюдение накрывало зону тревоги),
ложные тревоги 1.6% строк, вероятность тревоги за ≥66 циклов ~90%
(Каплан–Майер).** У 75% двигателей ложных тревог нет вовсе; стойкие
тревоги концентрируются в 8 агрегатах с нестационарной нормой.

Ключевой методологический принцип, зафиксированный в ходе работы:
**запас предупреждения без оценки ложных тревог не имеет смысла** —
версии B и C давали правдоподобные цифры запаса (194 и 167 циклов), но
ловили межагрегатную вариативность: детектор, срабатывающий всегда,
«предсказывает» любой отказ.

## Перенос на другой тип отказа (FD003)

Оба компонента применены к FD003 (деградация вентилятора) без переобучения:

| Компонент | FD001 (свой отказ) | FD003 (чужой) |
|---|---|---|
| Модель RUL, RMSE | 17.92 | 26.43 (+47%; наивный прогноз 41.40) |
| Обнаружение (цензурирование учтено) | 98% | 89% |
| Медианный запас | 91.5 цикла | 126 циклов |
| Ложные тревоги (RUL &gt; 125) | 1.6% строк | 18.6% строк |

Модель удерживает универсальный сигнал старения (26.4 против 41.4
наивного), но теряет специфичную часть. Детектор сохраняет
чувствительность к дрейфу, однако калибровка «дрейф → время до отказа»
специфична типу отказа. Рейтинг сенсоров частично подтверждает физику:
вентиляторные каналы (Nf, NRf, BPR) поднялись в топ, но доминируют каналы
ядра — деградация вентилятора распространяется на компрессорный тракт.
Особенности FD003: sensor_6 — квантованный шум (17 уровней), провалы
вентиляторной частоты до общего уровня у нескольких агрегатов
(системный эффект), каналы делятся на две группы по времени начала
деградации (~250 и ~100 циклов до отказа).

Вывод: сигнал деградации универсален, его интерпретация — нет;
обоснован классификатор типа отказа (маршрутизатор) с калибровкой
компонентов под каждый режим.

## Планы развития

- FD002/FD004 (6 рабочих режимов): нормировка сенсоров относительно
  режима → кластеризация паттернов деградации на FD004 → метки для
  маршрутизатора
- Каскад «детектор → модель RUL»: детектор решает «здоров/деградирует»,
  регрессия считает остаток только в зоне риска
- Перекалибровка детектора для 8 агрегатов с нестационарной нормой

Итоговая система: телеметрия → (нормировка по режиму) → классификатор
типа отказа → специализированная модель RUL → планирование обслуживания.
