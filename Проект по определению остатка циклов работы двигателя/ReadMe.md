Предиктивное обслуживание ГЭУ: прогноз остаточного ресурса по телеметрии на датасете NASA CMAPSS
train_FD001.txt   — телеметрия двигателей, запись до отказа
test_FD001.txt    — телеметрия двигателей, запись обрывается ДО отказа
RUL_FD001.txt     — сколько циклов реально осталось у каждого тестового двигателя
Набор данных: FD001 Тренировочные траектории: 100 Тестовые траектории: 100 Условия: ОДИН (Уровень моря) Режимы отказов: ОДИН (Деградация HPC)  
 Наборы данных состоят из множества многомерных временных рядов. Каждый набор данных далее подразделяется на обучающую и тестовую подгруппы. Каждый временной ряд получен от отдельного двигателя, то есть данные можно считать полученными от парка двигателей одного типа. Каждый двигатель изначально имеет разную степень износа и производственных отклонений, неизвестных пользователю. Этот износ и отклонения считаются нормальными, то есть не считаются неисправностью. 
 Существует три рабочих режима, которые существенно влияют на производительность двигателя. Эти режимы также включены в данные. Данные загрязнены шумом датчиков. В начале каждого временного ряда двигатель работает нормально, а неисправность возникает в какой-то момент во время ряда. В обучающем наборе неисправность нарастает по мере приближения к отказу системы. В тестовом наборе временной ряд заканчивается за некоторое время до отказа системы. 
 Цель конкурса — предсказать количество оставшихся рабочих циклов до отказа в тестовом наборе, то есть количество рабочих циклов после последнего цикла, в течение которых двигатель будет продолжать работать. Также предоставлен вектор истинных значений остаточного срока службы (RUL) для тестовых данных. 
 Данные представлены в виде сжатого в формате ZIP текстового файла с 26 столбцами чисел, разделенных пробелами. Каждая строка представляет собой снимок данных, полученных в течение одного рабочего цикла, каждый столбец соответствует отдельной переменной. 
Столбцы соответствуют: 1) номеру блока(engine_id); 2) времени (cycle); 3) рабочему режиму 1(os_1); 4) рабочему режиму 2(os_2); 5) рабочему режиму 3(os_3) 3; 6) измерению датчика 1(sensor_1); 7) измерению датчика 2(sensor_2); ... 26) измерению датчика 21 (sensor_21)
