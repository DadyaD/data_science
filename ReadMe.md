## Прогнозирование остаточного ресурса двигателя (predictive maintenance)

По телеметрии авиадвигателя (NASA CMAPSS) — два компонента системы
предиктивного обслуживания, проверенные на незнакомых данных:

- **Модель RUL** (сколько циклов осталось): LightGBM, native CV 17.93–19.85
  на трёх наборах; test 17.92 (FD001); честные transfer-эксперименты
- **Детектор начала деградации** (раннее предупреждение): обнаружение
  90–98% на всех четырёх наборах, ложные тревоги 1.6–18.6%, один код
- **Маршрутизатор типов отказов**: кластеризация сигнатур без меток
  (silhouette 0.56), per-cluster OOF 17.77

История: четыре версии детектора до рабочей, четыре подтверждённых
принципа, все негативные результаты задокументированы.

Стек: Python, pandas, LightGBM, scikit-learn, matplotlib, Git
