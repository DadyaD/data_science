## Прогнозирование остаточного ресурса двигателя (predictive maintenance)

По телеметрии авиадвигателя (NASA CMAPSS) предсказываю остаток циклов
до отказа. Заодно проверил на практике, что мне близко по опыту:
модель, обученная на испытательной телеметрии, реально работает.

- **Результат: test RMSE 17.92 цикла**, CV 18.70 ± 0.59 (GroupKFold)
- Честная методология: одна тестовая выборка, групповая CV,
  задокументированные негативные результаты
- Стек: Python, pandas, LightGBM, scikit-learn
